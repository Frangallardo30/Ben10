# Guardar la fecha real de cada propuesta

## Estado

Pendiente

## Pedido

La columna heredada `expires_at` se usa actualmente para ordenar el historial y se resta un día para mostrar la fecha de creación. Ya no hay vencimiento automático, así que el nombre y la interpretación son confusos.

## Criterios de aceptación

- [ ] Las propuestas nuevas guardan `created_at` con la hora real de creación.
- [ ] Las propuestas existentes conservan su fecha visible y su orden en el historial.
- [ ] La migración se puede repetir sin duplicar ni perder datos.
- [ ] `/historial` muestra la fecha correcta para registros nuevos y anteriores.
