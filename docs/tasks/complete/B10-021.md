# Consultar quién votó y qué opción eligió

## Estado

Hecha

## Pedido

Agregar «Ver votos» a las propuestas de aura y publicar los cambios. Mostrar la opción actual de cada votante, incluso después del cierre.

## Criterios de aceptación

- [x] Botón accesible a miembros del mismo servidor en propuestas abiertas y cerradas.
- [x] Lista privada paginada con persona y opción actual, sin modificar votos ni el mensaje público.
- [x] Vacíos, límites y errores claros; aislamiento de servidores y exclusión de anuladas/ajustes administrativos.
- [x] Las propuestas anteriores con ID de mensaje conocido reciben el botón mediante sincronización recuperable.
- [x] Pruebas, runtime local y empaquetado comprobados; publicación y límites remotos registrados por separado.

## Implementación

Se agregó el botón Ver votos a propuestas abiertas y cerradas. Consulta SQL única con visibilidad, conteos y página consistente; veinte personas por página y opción actual. Los botones difieren con flags 64 antes de D1 y completan su propia respuesta privada. Las consultas no actualizan el mensaje público ni preparan tablas. La preparación de escrituras/cron encola una sola actualización de mensajes históricos conocidos mediante `vote_list_button_v1`.

No cambia la política de votos ni los permisos administrativos. Las consultas excluyen anuladas y ajustes administrativos, incluso con IDs de botones anteriores. Se actualizaron la spec, /info, la guía y las comprobaciones de cierre para exigir únicamente el botón de consulta.

## Publicación y límites

El usuario autorizó subir los cambios a main para activar el despliegue conectado de Cloudflare. La confirmación de ejecución en producción no se infiere de las pruebas locales. El entorno no tiene credenciales de Cloudflare y la API de GitHub respondió Forbidden en consultas de estado anteriores. La prueba real de Discord sigue en B10-006.

Los mensajes sin ID conocido no se pueden actualizar automáticamente. El cron procesa hasta veinte revisiones por ejecución y conserva reintentos; una cola grande necesita varias ejecuciones. Las listas privadas previas son copias del momento de consulta, incluso después de cambiar un voto o anular la propuesta.
