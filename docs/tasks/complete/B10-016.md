# Configurar el bot por servidor

## Estado

Hecha

## Pedido

Permitir elegir el rol decisor, los umbrales de votos y el canal de propuestas en cada servidor.

## Criterios de aceptación

- [x] Solo personas autorizadas pueden cambiar la configuración.
- [x] Cada servidor conserva sus valores sin afectar a otros; hay valores predeterminados seguros.
- [x] Las propuestas abiertas conservan una regla de cierre definida aunque cambie la configuración.
- [x] `/info` refleja la configuración vigente.

## Implementación

Se añadió `/config ver` (consulta privada disponible a miembros) y `/config cambiar` (Administrar servidor o Administrador). Permite elegir rol, umbral normal, umbral para imponerse y canal. Los umbrales admiten enteros 1–100 con imponerse ≥ normal. `canal_libre:true` retira la restricción; no se puede combinar con canal. Los valores omitidos se conservan y un servidor nuevo necesita un rol explícito, distinto de @everyone.

Antes de guardar un canal de texto o anuncios del mismo servidor se consultan el canal, los roles y el miembro bot en Discord. Se calculan permisos efectivos y sobrescrituras: Ver canal, Enviar mensajes e Insertar enlaces, o Administrador. Los fallos no aplican el cambio. Toda respuesta de configuración es efímera.

`guild_config` guarda valores y versión por servidor. Una edición concurrente con versión vieja se rechaza para evitar sobrescrituras; `guild_config_attempts` impide que reentregar un cambio revierta otro posterior. La creación consulta las reglas activas dentro del lote e inserta una copia inmutable en `proposal_rules`. Votos, umbrales SQL y embeds usan esa copia, no la configuración vigente. Las propuestas anteriores siguen operando en su canal original.

La migración crea las tablas automáticamente, conserva 4/6 y el rol histórico en todas las propuestas heredadas y configura una sola vez los servidores con propuestas previas. La marca guild_config_v1 evita que servidores posteriores hereden ese rol. No borra votos ni altera estados. `/info` en servidores ahora se difiere para leer las reglas vigentes; en DM conserva una guía general. Registro de comandos actualizado a v8, README, spec, permisos de invitación y guía operativa actualizados.
