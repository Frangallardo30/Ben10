# Caducar votaciones abiertas

## Estado

En curso

## Pedido

Cerrar sin efecto sobre el aura las propuestas que no alcancen los votos necesarios en 24 horas.

## Criterios de aceptación

- [x] Una propuesta abierta vence a las 24 horas; el cron la marca como vencida y solicita quitar los botones del mensaje si conserva su ID.
- [x] Un voto recibido tras el vencimiento no cuenta aunque el cron aún no haya corrido.
- [x] El aura y el historial de aprobaciones no incluyen propuestas vencidas.
- [x] Una carrera entre voto y caducidad no reabre ni aprueba una propuesta ya vencida.
- [x] La ficha `/info` y la spec explican el plazo; se documenta cómo se tratan mensajes antiguos sin ID.

## Implementación

El Worker guarda el ID del mensaje original después de responder a `/aura` y también lo recupera al recibir un voto. El cron existente, que corre cada cinco minutos, marca como vencidas las propuestas abiertas tras 24 horas, intenta actualizar hasta 20 mensajes por ejecución y reintenta errores de Discord. La respuesta a un botón vencido actualiza el mensaje y retira sus botones. Una actualización condicional de D1 dentro del lote de voto evita contar votos después del plazo. `proposal_expiry_sync` registra qué mensajes ya se actualizaron y se crea automáticamente en D1.

Se reforzó la comprobación del plazo dentro del lote usando `unixepoch()` de D1, para evitar que una espera antes de ejecutar el lote use una hora capturada antes del vencimiento. Las pruebas cubren ese límite con el cuarto voto del rol, un voto tras el cron, exclusión del aura e historial, propuestas futuras y aprobadas intactas, y reintento de edición tras un error 503 simulado de Discord.
