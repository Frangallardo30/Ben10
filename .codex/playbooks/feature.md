# Nueva función o cambio

1. Identificar el comportamiento actual en `docs/specs/`, el código y las tareas relacionadas.
2. Abrir una tarea desde la plantilla con criterios de aceptación concretos.
3. Cambiar código y spec juntos. Mantener los contratos de Discord y D1 indicados en las reglas de ingeniería.
4. Ejecutar las comprobaciones aplicables y registrar resultados en la tarea.
5. Revisar el diff, actualizar el índice y cerrar la tarea cuando corresponda.

Esta guía no es un comando slash de Codex.
