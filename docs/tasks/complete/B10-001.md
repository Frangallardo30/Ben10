## Pedido

Revisar firmas, postulación propia, votos generales y del rol, cierre de propuestas, perfiles e historial. Dejar comprobaciones repetibles para evitar regresiones.

## Criterios de aceptación

- [x] Una firma válida de Discord se acepta y una firma alterada o antigua se rechaza.
- [x] Quien propone o recibe el aura no puede votar; el resto puede votar y cambiar su voto.
- [x] Los cierres con cuatro o seis votos del rol se comprueban en ambos sentidos.
- [x] Una prueba de flujo completo cubre propuesta, votos, perfil e historial.
- [x] El workflow de GitHub está configurado para ejecutar las pruebas en cada push y pull request.

## Implementación

`src/voting.js` contiene las consultas y reglas de cierre. `test/` comprueba la firma, las consultas SQL y las interacciones completas con una base SQLite local. `check.yml` automatiza las pruebas y el empaquetado de Wrangler. Se corrigió el avatar predeterminado cuando el ID no tiene formato numérico y se evitó repetir la preparación de D1 en cada interacción del mismo Worker.
