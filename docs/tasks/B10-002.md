# Mantener el embed correcto ante votos simultáneos

## Estado

Pendiente

## Pedido

Evitar que respuestas de votos concurrentes se apliquen fuera de orden y dejen el mensaje con recuentos o botones anteriores al estado guardado en D1.

## Criterios de aceptación

- [ ] D1 conserva un único voto por persona y un único estado final por propuesta bajo concurrencia.
- [ ] El mensaje acaba mostrando el recuento y estado final guardados, incluso si dos interacciones llegan casi a la vez.
- [ ] Los botones no reaparecen después de cerrar la propuesta.
- [ ] Una prueba reproduce el orden de respuestas que antes dejaba el embed desactualizado.

## Implementación

Pendiente. Evaluar una sincronización posterior del mensaje mediante el Bot Token y `message_id`, con un control de versión para no aplicar una edición antigua después de una nueva.

## Validación

- [ ] Tests y chequeos relevantes en verde.
- [ ] Prueba manual con varios votos simultáneos en Discord.
