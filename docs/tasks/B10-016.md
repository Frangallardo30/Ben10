# Configurar el bot por servidor

## Estado

Pendiente

## Pedido

Permitir elegir el rol decisor, los umbrales de votos y el canal de propuestas en cada servidor.

## Criterios de aceptación

- [ ] Solo personas autorizadas pueden cambiar la configuración.
- [ ] Cada servidor conserva sus valores sin afectar a otros; hay valores predeterminados seguros.
- [ ] Las propuestas abiertas conservan una regla de cierre definida aunque cambie la configuración.
- [ ] `/info` refleja la configuración vigente.
