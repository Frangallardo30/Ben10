## Estado

Hecha

## Pedido

Explicar qué hace `.claude` en FrangaFlix y establecer pautas equivalentes y persistentes para trabajar con Codex en Ben10Bot, junto con el seguimiento de tareas.

## Criterios de aceptación

- [x] Identificar qué partes de `.claude` son contexto y proceso, y cuáles dependen de Claude.
- [x] Crear un punto de entrada que Codex pueda leer y una guía `.codex` ajustada a este bot.
- [x] Vincular tareas con una especificación vigente del comportamiento.
- [x] Registrar este cambio en el índice de tareas y enlazar las guías desde el README.

## Implementación

Se revisó `.claude` y `CLAUDE.md` de FrangaFlix. `AGENTS.md` enlaza las nuevas guías de `.codex/`, con contexto, reglas, flujo de tareas y guías de implementación y revisión. `docs/specs/aura.md` documenta el comportamiento vigente, separado del historial de tareas. No se copiaron comandos ni agentes de Claude como si Codex los ejecutara automáticamente.
