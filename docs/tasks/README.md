# Tareas de Ben10Bot

Cada tarea tiene un archivo propio siguiendo [TEMPLATE.md](TEMPLATE.md). Al trabajar en una tarea, actualizá su estado, marcá criterios comprobados y anotá la validación real. Las pruebas locales y la implementación en Cloudflare se registran por separado. Las tareas pendientes o en curso permanecen en esta carpeta; al marcarlas `Hecha`, mové su archivo a [`complete/`](complete/) y actualizá los enlaces. Si se reabre una tarea, devolvela a esta carpeta y actualizá su estado y enlaces. Conservá siempre su ID.
