# Añadir ranking de aura

## Estado

En curso

## Pedido

Crear `/ranking` para mostrar a las personas con más aura en el servidor.

## Criterios de aceptación

- [x] El ranking suma solo propuestas aprobadas y separa servidores.
- [x] El orden y los empates son estables; el mensaje es legible y respeta límites de Discord.
- [x] `/info` incluye el comando.

## Implementación

Se añadió `/ranking` al registro y al despacho de comandos. Una consulta preparada en D1 agrupa por usuario dentro del servidor y suma solo propuestas aprobadas. Devuelve como máximo diez entradas, con aura descendente, puesto compartido mediante RANK y desempate estable por ID ascendente (1, 1, 3). Incluye totales cero y negativos; los usuarios sin movimientos aprobados no aparecen. El límite puede cortar un empate.

La respuesta diferida presenta un embed breve, sin motivos ni menciones que generen notificaciones, con un mensaje claro si no hay datos. No cambia el esquema ni espera migraciones para leer. `/info`, README y la spec incluyen el comando. Se incrementó a v5 la versión de registro para que el proceso automático publique el nuevo comando y repare una lista donde falte.
